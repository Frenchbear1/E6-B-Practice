# E6-B Practice

A single-page practice app for E6-B style aviation math.

## Features

- Addition, subtraction, multiplication, and division practice
- Custom digit controls for arithmetic problems
- Random max-digit mode
- E6-B word problems for time/speed/distance, fuel, climb/descent, ETA, and wind basics
- Timer, score, accuracy, and streak
- End review for missed questions

Open `index.html` locally, or use the GitHub Pages link once Pages finishes publishing.
